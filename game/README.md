# Игровое приложение - Курсовая работа

## 📋 Описание проекта

Игровое приложение с системой уровней, рейтингом игроков и ограничением по времени. Работает локально на компьютере пользователя с использованием localStorage для сохранения данных.

## 🎯 Реализованные требования

### ✅ Выполнено на текущий момент:

1. **Миниавторизация** - Ввод или генерация никнейма
2. **Рейтинг игроков** - Таблица лидеров с сортировкой по очкам
3. **3 уровня игры** - Структура для трех уровней сложности
4. **Ограничение по времени** - Каждый уровень имеет таймер
5. **Ускорение на уровнях** - Время уменьшается с каждым уровнем
6. **Подсчет баллов** - Система начисления очков с множителями
7. **Штрафные баллы** - Вычитание очков за ошибки
8. **Сохранение данных** - localStorage для хранения результатов
9. **Минимум 3 страницы**:
   - Главная (index.html)
   - Авторизация (auth.html)
   - Игра (game.html)
   - Результаты (results.html)
10. **События клавиатуры** - ESC для паузы, Enter для продолжения
11. **Двойной клик** - Копирование имени игрока в таблице рейтинга
12. **Анимации** - CSS анимации для всех элементов
13. **Динамическое создание элементов** - Генерация UI на лету
14. **Экспорт данных** - Выгрузка результатов в JSON

### 🔄 Требуется доработка (зависит от темы игры):

- Произвольная генерация вопросов (заглушка готова)
- Случайное расположение элементов игры
- Специфические виды событий (перемещение, drag-and-drop)
- Игровая логика в зависимости от темы

## 🚀 Запуск приложения

1. Откройте файл `index.html` в браузере
2. Или используйте Live Server в VS Code
3. Или откройте через локальный сервер

## 🎮 Как играть

1. **Авторизация**: Введите никнейм или сгенерируйте случайный
2. **Игра**: 
   - Пройдите 3 уровня
   - На каждом уровне 5 вопросов
   - Время ограничено (60/45/30 секунд)
   - Зарабатывайте очки за правильные ответы
   - Бонус за скорость
3. **Результаты**: Просмотрите свой результат и рейтинг игроков

## 💾 Система сохранения данных

- `leaderboard` - Рейтинг всех игр
- Автоматическое сохранение после каждой игры

## 🎯 Система очков

- **Базовые очки**: 10 за правильный ответ
- **Множители уровней**:
  - Уровень 1: x1
  - Уровень 2: x1.5
  - Уровень 3: x2
- **Бонус за скорость**: +2 очка за каждую сэкономленную секунду
- **Штраф**: -5 очков за неправильный ответ
- **Бонус за время**: Оставшееся время × 2 × множитель уровня
