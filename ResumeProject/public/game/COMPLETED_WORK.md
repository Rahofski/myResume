4. Добавить специфические события (drag-and-drop, контекстное меню и т.д.)

## 📝 Как начать работать

1. Откройте `index.html` в браузере для тестирования
2. Прочитайте `INTEGRATION_GUIDE.md` для инструкций
3. Определите тему игры
4. Заполните `data.js` игровыми данными
5. Реализуйте игровую логику в `game.js`
6. Тестируйте и дорабатывайте
